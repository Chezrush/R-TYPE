# R-Type developer documentation

R-Type is a networked shoot'em up built on a small game engine. This site explains how it is
put together so that a new contributor can find their way around quickly.

| I want to... | Read |
| --- | --- |

| understand the layers and the threads | [Architecture](architecture/overview.md) |
| write a client or debug packets | [Protocol](protocol/rtype-protocol.md) |
| add gameplay (component, system, enemy) | [Adding a system](guides/adding-a-system.md) |
| know why we picked each technology | [Comparative study](comparative-study.md) |
| see how the game supports every player | [Accessibility](accessibility.md) |
| contribute code | [Contributing](contributing.md) |
